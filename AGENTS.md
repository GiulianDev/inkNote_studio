# Istruzioni Permanenti del Progetto

- **Conferma esplicita obbligatoria**: chiedere sempre conferma esplicita all'utente prima di effettuare qualsiasi modifica a codice, file di configurazione o documentazione.
- **Aggiornamento costante di `log.md`**: ogni volta che vengono effettuate modifiche al progetto, aggiornare sempre il file `log.md` aggiungendo la relativa voce di changelog allineata alla versione corrente (`package.json` / `scripts/sync-release.mjs`).
